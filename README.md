# Lorenzo Uttini — academic website

A static academic website hosted on GitHub Pages. No build step or dependencies are required.

## Local preview

From this directory, run:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open <http://localhost:8000> in your browser. Stop the server with `Ctrl+C`.

## Editing

- `index.html`: biography, publications, experience, and awards.
- `style.css`: responsive layout, typography, and print styles.
- `CV_LorenzoUttini.pdf`: downloadable CV, updated from the supplied CV.
- `photo_self.JPG`: profile portrait; publications and experience use text-only entries.

The publication titles, author order, statuses, and links follow the supplied CV.
